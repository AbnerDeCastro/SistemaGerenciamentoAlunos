# Sistema de Gerenciamento de Alunos

Projeto desenvolvido em **Java** com o objetivo de praticar os fundamentos da linguagem e conceitos de **Programação Orientada a Objetos (POO)**.

## 📚 Sobre o projeto

Atualmente, o sistema permite cadastrar um aluno informando:

* Nome
* Idade
* Três notas

A aplicação calcula automaticamente a média do aluno e informa sua situação:

* **Aprovado** — média maior ou igual a 7
* **Recuperação** — média maior ou igual a 5
* **Reprovado** — média abaixo de 5
